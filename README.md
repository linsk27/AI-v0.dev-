# AI-v0.dev-

AI-v0.dev- 是一个用 v0、Next.js、React、TypeScript 和 Tailwind CSS 搭出来的 AI 工程师学习计划仪表盘原型。

它不是默认模板仓库，而是一个前端产品原型：把 3 个月 AI 工程师冲刺计划拆成时间线、项目卡片、知识体系、里程碑、任务进度、数据导入导出和本地状态管理。

English summary: AI-v0.dev- is a Next.js and TypeScript prototype for AI learning dashboards, v0.dev UI experiments, product interface design, progress tracking, project cards, and local-first learning plan management.

项目展示页：[linsk27 projects - AI-v0.dev-](https://linsk27.github.io/projects/ai-v0-dev/)

如果你关注 AI UI prototype、v0.dev workflow、Next.js dashboard、Tailwind interface design 或学习计划产品原型，欢迎 Star；我会继续把可复用的界面结构和交互沉淀出来。

## 核心功能

- 3 个月 AI 工程师冲刺计划时间线
- 每周任务、实践内容、输出目标和学习资源
- 项目卡片、简历亮点和完成进度
- 知识体系和学习资源视图
- 里程碑进度和总体统计
- 本地数据导入、导出和重置
- v0 + shadcn/ui 风格的前端交互实验

## 技术栈

- Next.js
- React
- TypeScript
- Tailwind CSS
- shadcn/ui
- Radix UI
- React hooks + localStorage
- v0.dev workflow

## 本地运行

```bash
pnpm install
pnpm dev
```

打开：

```text
http://localhost:3000
```

也可以使用 npm：

```bash
npm install
npm run dev
```

## 适合参考什么

- 用 v0 快速生成可继续迭代的 Next.js 页面
- AI 学习计划、进度管理、任务看板和项目卡片的产品结构

- 前端原型如何从静态页面扩展到可编辑、可导入导出的工具
